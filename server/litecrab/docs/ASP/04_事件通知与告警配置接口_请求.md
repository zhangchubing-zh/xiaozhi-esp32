### 接口名称

set_event_notify_info.asp

### 功能

告警事件通知信息设置接口，通过 Type 参数区分不同操作（短信/邮箱配置测试、收件箱配置增删改、手机号码配置增删改、告警通知配置增删改、告警延时设置、定时提醒等）。各 Type 功能如下：

- **Type=0**：测试手机短信配置（请求方式为 POST）。
- **Type=1**：测试发件箱配置，原始为字符串拼接格式（`~` 分隔）。备注：为了 fossid 整改 base64，以上字符串格式的 Type=1 将被代替，不做保留、不做兼容性处理；后续新增 JSON 格式代替（见下方 JSON 说明）。
- **Type=2**：测试收件箱配置（发送测试邮件）。
- **Type=3**：添加收件箱配置。
- **Type=4**：修改收件箱配置。
- **Type=5**：删除收件箱配置。
- **Type=6**：测试手机号码配置。
- **Type=7**：添加手机号码配置。
- **Type=8**：修改手机号码配置。
- **Type=9**：删除手机号码配置。
- **Type=10**：添加告警通知配置。
- **Type=11**：修改告警通知配置。
- **Type=12**：删除告警通知配置。
- **Type=13**：设置告警延时。
- **Type=14**：清除发件箱配置。
- **Type=15**：测试密码找回方式（测试邮件和短信）。
- **Type=16**：添加告警通知配置（收编 type=10 请求，JSON 格式）。
- **Type=17**：修改告警通知配置（收编 type=11 请求，JSON 格式）。
- **Type=18**：设置定时提醒间隔配置（新增，JSON 格式）。

**平台前台调用**：`<% SetNotifyCfgInfo(type, para); %>`

**后台接口**：`extern INT32 EMAP_AspSetNotifyCfgInfo(INT32 eid, Webs *wp, INT32 argc, CHAR **argv);`

**后台是否记录操作记录**：记录操作记录。

### 接口名称

set_find_equipinfo.asp

### 功能

设置发现设备参数信息接口，用于对新接入的设备进行测试或新增设备操作（目前仅 ECC 产品使用），以及处理 SMU 发现参数的增删改。各 Type 功能如下：

- **Type=0/1**：设置发现设备参数信息（V2R2C00）。Type=0 测试设备，Type=1 填加设备（用于新增设备操作）。
- **Type=3**：处理设置发现参数（SMU 使用，JSON 格式），发现参数设备增删改。

**前台请求使用**：`set_find_equipinfo.asp?type=&para1=&para2=&para3=&para4=&para5=&para6=`

### 接口名称

get_alarm_cfg.asp

### 功能

告警配置查询接口，根据 Type 返回语言列表、登录页语言资源、告警级别/使能/关联继电器/摄像头/音响/显示表达式/告警名称等。各 Type 功能如下：

- **Type=0**：获取语言列表。
- **Type=1**：获取登录页面各种语言下使用的语言资源。
- **Type=2**：根据设备类型获取告警级别（原请求，app 使用）。
- **Type=3**：根据设备类型获取告警使能。
- **Type=5**：根据设备类型查询告警关联继电器。
- **Type=6**：查询告警关联摄像头。
- **Type=7**：查询音响设备信息。
- **Type=8**：获取一个设备类型下指定设备告警的显示表达式。
- **Type=9**：获取一个设备类型下指定设备告警的显示表达式。
- **Type=10**：根据设备类型获取告警名称。
- **Type=11**：获取一个设备类型下指定设备告警的显示表达式。
- **Type=12**：根据设备实例获取告警级别（新增加，支持 JSON 格式返回）。
- **Type=13**：根据设备类型获取告警信息。
- **Type=14**：根据设备类型查询指定告警的使能状态，包含该类型下所有实例的使能状态。

（Type=4 未出现在文档中）

**前台请求使用**：`./get_alarm_cfg.asp?type=&para=`

**后台接口**：`extern INT32 EMAP_AspGetAlarmConfigInfo(INT32 eid, Webs *wp, INT32 argc, CHAR **argv);`
