### 接口名称
get_update_info.asp

### 功能
get_update_info.asp 与 get_update_info_ex.asp 调用的是同一个后台接口。get_update_info_ex.asp 进行了参数扩展，本 asp 对应不同 type 的功能说明见 get_update_info_ex.asp。get_update_info.asp 有 3 个参数，get_update_info_ex.asp 参数为 8 个；建议产品切换使用 get_update_info_ex.asp 接口进行数据请求。

后台接口：`INT32 EMAP_AspDisplayUpdateRetInfo(INT32 eid, Webs *wp, INT32 argc, CHAR **argv)`

各 Type 功能及后台是否记录操作记录：

| Type | 功能 | 后台是否记录操作记录 |
| --- | --- | --- |
| 0 | 根据type获取升级文件列表 | 不会记录操作记录 |
| 1 | 创建升级任务（不区分单并机） | 会记录操作记录 |
| 2 | 删除升级文件 | 记录操作记录 |
| 3 | 查询升级进度 | 记录操作记录 |
| 4 | 获取升级包上传状态请求 | 不会记录操作记录 |
| 5 | 创建升级任务（单机） | 会记录操作记录 |
| 6 | 创建升级任务（并机） | 会记录操作记录 |
| 7 | 清空上传升级包 | 不会记录操作记录 |
| 8 | 查询升级的状态 | 不记录操作记录 |
| 9 | 广播升级创建升级任务 | 会记录操作记录 |
| 10 | 查询升级进度（广播升级） | 记录操作记录 |
| 11 | 检查升级包上传是否正常 | 不记录操作记录 |

### 接口名称
proc_first_login.asp

### 功能
处理开站场景下首次登陆监控时无用户密码，设置 web 管理员用户密码场景。

后台接口：`INT32 EMAP_AspProcFirstLogin ( INT32 eid, Webs *wp, INT32 argc, CHAR **argv)`

各 Type 功能及后台是否记录操作记录：

| Type | 功能说明 | 后台是否记录操作记录 |
| --- | --- | --- |
| 0 | 默认用户首次登陆配置口令功能使用。该接口只能在首次登陆之前使用，首次登陆（默认用户的口令已经被成功设置）之后，将返回无效信息。在产品使用默认用户首次登陆配置口令功能后，用于查询 web 是否需要强制用户配置默认用户口令。【V3R21C00版本新增】 | 不记录操作记录 |
| 1 | 默认用户首次登陆配置口令功能使用。该接口只能在首次登陆之前使用，首次登陆（默认用户的口令已经被成功设置）之后，将返回失败。在产品使用默认用户首次登陆配置口令功能后，用于设置默认用户的口令信息。【V3R21C00版本新增】 | 用户管理记录操作记录 |
| 2 | 用于获取产品注册用户口令信息字符串。该接口只能在首次登陆之前使用，首次登陆（默认用户的口令已经被成功设置）之后，将返回失败。GetResAndDescriptStrById 接口当前仅能获取白名单字符串、字符串最小长度、字符串最大长度、字符串对应描述资源，对于用户口令类的数据，不支持密码复杂度信息、密码必须包含的字符种类等。 | 不记录操作记录 |

### 参数

**请求信息（Type=0）**

Type：0（获取首次登陆标记）

**响应信息（Type=0）**

JSON 信息域（初始版本：V3R21C00）：

| 名称 | 值 | 说明 |
| --- | --- | --- |
| errcode | | 0:查询ok；其他:查询失败 |
| usrInfo | [ { … } ] | 用户信息数组，元素字段如下 |

usrInfo 元素字段：

| 名称 | 说明 |
| --- | --- |
| usrname | 用户名 |
| priv | 用户权限（管理员/工程师/操作员） |
| optSrc | 用户操作源（WEB/LUI等） |
| firstLoginFlag | 首次登陆标记 0:首次登陆；1:非首次登陆 |

响应 JSON 结构示意：
```json
{
  "errcode": 0,
  "usrInfo": [
    { "usrname": "", "priv": "", "optSrc": "", "firstLoginFlag": 0 },
    { "usrname": "", "priv": "", "optSrc": "", "firstLoginFlag": 0 }
  ]
}
```

**请求信息（Type=1）**

Type：1（首次登陆场景下设置默认用户的口令）

Para1（JSON，初始版本：V3R21C00）：

| 名称 | 值 | 说明 |
| --- | --- | --- |
| password | String | 默认用户口令，口令字符串需满足特殊字符校验，满足产品注册的用户可设字符以及口令复杂度 |

请求 JSON 结构示意：
```json
{ "password": "" }
```

**响应信息（Type=1）**

| 名称 | 说明 |
| --- | --- |
| errcode | 0:设置成功；其他:设置失败 |

响应 JSON 结构示意：
```json
{ "errcode": 0 }
```

**请求信息（Type=2）**

Type：2（获取产品注册字符串信息）

**响应信息（Type=2）**

（初始版本：V3R21C00）

| 名称 | 说明 |
| --- | --- |
| errcode | 0:获取成功；其他:获取失败（获取失败场景下，没有其他字段） |
| whiteList | 白名单字符串 |
| minLen | 最小长度 |
| maxLen | 最大长度 |
| descriptStr | 描述资源 |
| pswdComplex | 密码复杂度 |
| pswdContain | 密码必须包含的字符类型。按照字节bit的规则进行处理，bit位置1表示需要包含该类型字符，置0表示不限制字符类别。bit0-大写，bit1-小写，bit2-数字，bit3-特殊字符（除大小写、数字以外的字符类型） |

响应 JSON 结构示意：
```json
{
  "errcode": 0,
  "whiteList": "",
  "minLen": 0,
  "maxLen": 0,
  "descriptStr": "",
  "pswdComplex": "",
  "pswdContain": 0
}
```

### 示例

前台请求使用：
```
./proc_first_login.asp? type=type&data= data1
```

平台前台调用：
```
<% ProcFirstLogin (type, data); %>
```
