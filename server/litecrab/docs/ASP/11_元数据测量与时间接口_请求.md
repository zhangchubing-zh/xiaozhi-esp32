### 接口名称

get_metadata_info.asp

### 功能

获取设备/信号相关的元数据信息，根据 Type 参数分为多种查询类型：

- **Type=0**：获取所有元数据信息（按设备类型/实例查询）
- **Type=1**：获取所有已修改元数据信息
- **Type=2**：查询不同设备类型的元数据信息
- **Type=3**：查询批量修改元数据信息
- **Type=4**：查询已加载的语言信息
- **Type=5**：查询元数据修改配置

**后台接口**：`INT32 EMAP_AspGetMetaDataInfo(INT32 eid, Webs *wp, INT32 argc, CHAR **argv);`

**后台是否记录操作记录**：无需记录操作记录

### 参数

**前台请求使用（示例）**：
```
get_metadata_info.asp?type=type&para1=EquipTypeId&para2=EquipID&para3=SigTypeNum&para4=para&para5=para&para6=para&para7=para&para8=para&para9=para
```

**平台前台调用（示例）**：
```
<%GetMetaDataInfo(type,para1,para2,para3,para4, para5,para6,para7,para8,para9);%>
```

- Type=0、1、4、5：需要记录操作记录
- Type=2、3：设备管理记录操作记录
