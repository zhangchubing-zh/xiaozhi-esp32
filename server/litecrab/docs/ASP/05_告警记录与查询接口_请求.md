### 接口名称
get_alarm_record.asp

### 功能
获取录播（告警记录）相关配置信息，按 Type 区分功能：

- **Type=0**：获取录播配置规格
- **Type=1**：查询已配置的录播配置信息

后台接口：
```
INT32 EMAP_AspGetALmRecordInfo(INT32 eid, Webs *wp, INT32 argc, CHAR **argv);
```
后台是否记录操作记录：不记录操作记录。

### 参数

#### Type=0：获取录播配置规格

##### 请求信息
前台请求使用：
```
./get_alarm_record.asp?type=&para1=&para2=&para3=&para4=&para5=&para6=&para7=&para8="
```
平台前台调用：
```
<% GetAlarmRecordCfg(type, para1, para2, para3, para4, para5, para6, para7, para8); %>
```

| 参数 | 分隔符 | 说明 | 版本变更 |
|------|--------|------|----------|
| Type | | 0：获取录播配置规格 | |

##### 响应信息
信息域：
- `Error:"ERR"`
- `Normal: " AlmMaxNum~ RecEquipTypeMaxNumPerAlm~RecEquipMaxPerAlm ~RecSigMaxToatlNum ~RecSigMaxPerEquipType "`

| 内容 | 分隔符 | 说明 | 变更版本 |
|------|--------|------|----------|
| AlmMaxNum | ~ | 告警最大数量 | |
| RecEquipTypeMaxNumPerAlm | ~ | 每个告警可选择的录播设备类型最大数量 | |
| RecEquipMaxPerAlm | ~ | 每个告警信号可录播的设备最大数量（目前没有用） | |

| RecSigMaxPerEquipType | ~ | 每一个被录播的设备类型下的告警信号数量最大值 | |

### 接口名称
proc_unauthorized_request.asp

### 功能
按 Type 区分功能（多个为 V2R2C20 版本新增）：

- **Type=1**：找回密码之前，判断用户是否设置了密码找回方式，如果设置了密码找回方式，则返回验证码信息及密码找回具体信息。(V2R2C20新增)
- **Type=2**：查询验证码发送状态 (V2R2C20新增)
- **Type=3**：获取用户密码找回配置请求 (V2R2C20新增)
- **Type=4**：校验验证码 (V2R2C20新增)
- **Type=5**：通过验证码校验过后，修改密码，为了能单独控制此请求的权限，且前后台能与口令超期操作区分（前后台显示，处理不同），故新增此请求。(V2R2C20新增)
- **Type=6**：修改密码页面点击事件后用此请求刷新用户页面超时时间，有用户操作则页面不超时 (V2R2C20新增)
- **Type=7**：获取找回密码页面的发送间隔后台tick时间 (V2R2C20新增)
- **Type=8**：密码找回页面，当点击叉叉按钮，为了尽快释放IP占用，不在互斥，返回首页时清除后台用户节点 (V2R2C20新增)
- **Type=9**：密码找回时，查询验证码校验结果；多因素认证时，查询验证码页面是否失效

后台接口：
```
INT32 EMAP_AspProcUnunauthorizedRequest( INT32 eid, Webs *wp, INT32 argc, CHAR **argv)
```

后台是否记录操作记录：
- Type=1~4、6、7、8、9：不记录操作记录
- Type=5：记录操作记录
