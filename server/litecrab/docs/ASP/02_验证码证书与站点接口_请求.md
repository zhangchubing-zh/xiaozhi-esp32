后台接口：`extern INT32 EMAP_AspGetNotifyCfgInfo(INT32 eid, Webs *wp, INT32 argc, CHAR **argv);`

后台是否记录操作记录：Type=1/2/3/4/5/6/7 均不记录操作记录。
