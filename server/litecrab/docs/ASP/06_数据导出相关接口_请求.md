### 接口名称
get_export_info.asp

### 功能
查询正在导出的文件的状态。按 filetype（文件类型）区分查询内容，包括：获取所有设备配置文件、配置文件、故障信息、历史告警、活动告警、性能数据、操作日志、导出全部数据、南向设备故障信息、南向设备导出进度等，并可返回 JSON 格式数据。

后台接口：`INT32 EMAP_AspGetExportRetInfo(INT32 eid, Webs *wp, INT32 argc, CHAR **argv);`

后台是否记录操作记录：不记录操作记录。

### 参数

请求信息（前台请求使用）：
`get_export_info.asp?filetype=fileType&cmdId=id`

**filetype 参数（请求信息）：**

| 参数 | 分隔符 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| filetype | 无 | 文件类型。可选值：9（获取所有设备配置文件），10（获取配置文件），48（获取故障信息），1（获取历史告警），5（获取活动告警），2（获取性能数据），3（获取操作日志），0（获取导出全部数据），0x57（获取南向设备故障信息），0x32（获取南向设备导出进度）。filetype=9,10,48 |  |
| typenum | ~ | 数据类型个数 | V200R002C10版本新增后续字段，V200R002C10以前版本无后续字段 |
| reserve | ~ | 保留 |  |
| type1 | ~ | 数据类型1 |  |
| typevalue1 | ~ | 数据类型1的数值 |  |
| reserve | ~ | 保留字段 |  |

**cmdId 参数（请求信息）：**

| 参数 | 分隔符 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| cmdId | 无 | 请求ID |  |

响应信息（信息域）：
- Error: `"ERR"`
- Normal: 按 filetype 不同返回不同内容，如下。

**Filetype = 0x30 响应（信息域）：**

| 内容 | 分隔符 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| ResponseCode | 无 | 响应码：0-导出完成；1-导出中；3-网管正在导出 |  |
| CurrentExportId/ExportProgress | 无 | 当前导出Id/导出进度 |  |

指定压缩类型时返回 json 格式：

| 名称 | 值 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| errCode | int | 0：成功，其他：失败 |  |
| state | int | 导出状态：0-导出成功；1-导出中 |  |
| progress | int | 导出进度 |  |
| compressType | int | 压缩类型 |  |

**Filetype = 0x09 响应（信息域）：**

| 内容 | 分隔符 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| ResponseCode | 无 | 导出状态 |  |

**Filetype = 产品注册类型（app使用）响应（信息域）：**

| 内容 | 分隔符 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| ResponseCode | 无 | 响应码：0-导出成功；1-导出中；2-导出失败 |  |
| ExportProgress | 无 | 导出进度 |  |

指定压缩类型时返回 json 格式：

| 名称 | 值 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| errCode | int | 0：成功，其他：失败 |  |
| state | int | 导出状态：0-导出成功；1-导出中 |  |
| progress | int | 导出进度 |  |
| compressType | int | 压缩类型 |  |

**Filetype = 0x32 响应（信息域）：**

| 名称 | 值 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| errcode | int | 0：成功，其他：失败 |  |
| totalstate | int | 导出总状态：0：空闲；1：导出中；2：导出成功；3：导出失败；4：其他用户导出中 |  |
| exportinfolist | [{ equiptypeid: int, equipid: int, state: int, progress: int, fileName: str }] | 导出进度信息。equiptypeid: 设备类型id；equipid: 设备id；state: 设备导出状态（0-导出成功；1-导出中；2-导出失败；3-等待导出中）；progress: 导出进度；filename: 导出包名，仅在导出进度100时携带一次，前端根据此包名下载导出包 |  |

**Filetype = 其他（app使用）响应（信息域）：**

| 内容 | 分隔符 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| ExportProgress | 无 | 导出进度 |  |


### 接口名称
set_export_info.asp

### 功能
对正在导出的用户离开该页面时，清除其导出状态。type = 0,1,2。

后台接口：`INT32 EMAP_AspSetExportInfo(INT32 eid, Webs *wp, INT32 argc, CHAR **argv);`

后台是否记录操作记录：不记录操作记录。

### 参数

请求信息（前台请求使用）：
`set_export_info.asp?type=type&filetype=fileType`

**type 参数（请求信息）：**

| 参数 | 分隔符 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| type | 无 | 0：清除用户导出状态；1：按类型导出停止；2：选择导出停止 |  |

**filetype 参数（请求信息）：**

| 参数 | 分隔符 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| fileType | 无 | 文件类型 |  |

响应信息（信息域）：
离开页面时调用，不返回数据。
(1) 清除用户导出状态
(2) 按类型导出停止
(3) 选择导出停止

### 示例
前台请求使用：
```
set_export_info.asp?type=type&filetype=fileType
```
平台前台调用：
```
<% SetExportInfo(type, filetype); %>
```
