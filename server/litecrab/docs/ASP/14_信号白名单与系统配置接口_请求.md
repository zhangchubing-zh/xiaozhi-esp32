### 接口名称
set_signals_info.asp

### 功能
批量设置多个设备多个信号。
- 后台接口：`EMAP_AspSetSignalsInfo(int eid, Webs *wp, int argc, CHAR **argv)`
- 后台是否记录操作记录：需要记录操作记录。

### 参数

#### type 定义
| 参数 | 参数类型 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| "1" | type | 批量设置多个设备多个信号 | 22A新加 |

#### type=1 请求信息（para）
请求类型：

| 名称 | 值类型 | 说明 |
| --- | --- | --- |
| type | int | 请求类型 |
| equipList | array | 设备列表 |
| token | string | 二次认证token |

设备列表元素 `equipList[]`：

| 名称 | 值类型 | 说明 |
| --- | --- | --- |
| equipId | int | 设备ID |
| equipTypeId | int | 设备类型ID |
| sigList | array | 信号列表 |

签名列表元素 `sigList[]`：

| 名称 | 值类型 | 说明 |
| --- | --- | --- |
| sigId | int | 信号ID |
| sigValue | string | 信号值 |

#### 响应信息
| 名称 | 值类型 | 说明 |
| --- | --- | --- |
| errCode | int | 0：成功；其他：失败 |
| resultList | array | 结果列表 |

结果列表元素 `resultList[]`：

| 名称 | 值类型 | 说明 |
| --- | --- | --- |
| result | int/string | 单个设备设置结果（成功：0；失败：失败原因） |
| equipId | int | 设备ID |
| equipTypeId | int | 设备类型ID |
| sigResultList | array | 信号设置结果列表 |

信号设置结果列表元素 `sigResultList[]`：

| 名称 | 值类型 | 说明 |
| --- | --- | --- |
| sigId | int | 信号ID |
| setResult | string | 设置结果（成功：0；失败：失败原因） |

### 示例
前台请求使用：
```
./ set_signals_info.asp?para=
```
平台前台调用：
```
<% SetSignalsInfo;%>
```

set_ip_whitelist_info.asp

### 功能
设置 ip 白名单。
- 后台接口：`EMAP_AspSetIpWhiteListCfg(int eid, Webs *wp, int argc, CHAR **argv)`

### 参数

#### Type 定义
| 参数 | 参数类型 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| "0" | Type | 添加ip白名单 | （文档未给出） |
| "1" | Type | 删除ip白名单 | （文档未给出） |
| "2" | Type | 激活ip白名单 | （文档未给出） |

| 名称 | 值 | 值类型 | 说明 |
| --- | --- | --- | --- |
| type | 0 | int | 添加ip白名单 |

| 名称 | 值 | 说明 |
| --- | --- | --- |
| moduleName | str | 模块名称 |
| ipRange | str | ip范围 |
| ipType | int | ip地址类型 0：ipv4 1：ipv6 |
| ipWhiteListType | int | ip白名单地址类型 |

Para2:
| 名称 | 值 | 值类型 | 说明 |
| --- | --- | --- | --- |
| token | - | str | 二次认证返回token |

#### Type=0 响应信息
| 名称 | 值 | 说明 |
| --- | --- | --- |
| errCode | - | 0：表示添加成功；其它值：失败 |

#### Type=1 请求信息（删除 ip 白名单）
Para0:
| 名称 | 值 | 值类型 | 说明 |
| --- | --- | --- | --- |
| type | 1 | int | 删除ip白名单 |

Para1:
| 名称 | 值 | 说明 |
| --- | --- | --- |
| moduleName | str | 模块名称 |

Para2:
| 名称 | 值 | 值类型 | 说明 |
| --- | --- | --- | --- |
| token | - | str | 二次认证返回token |

#### Type=1 响应信息
| 名称 | 值 | 说明 |
| --- | --- | --- |

| --- | --- | --- | --- |

### 接口名称
get_time_refresh_data.asp

### 功能
数采新 web 页面定时查询信息，包括告警数量，系统时间，用户状态，退出时间等。
- 后台接口：`EMAP_AspGetTimeRefreshData(int eid, Webs *wp, int argc, CHAR **argv)`
- 后台是否记录操作记录：不需要记录操作记录。

### 参数

#### 请求信息（para）
| 名称 | 值 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| userId | int | 用户ID，在登录成功时会返回 | V300R025C00 |

#### 响应信息
| 名称 | 值 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| errCode | int | 0：成功，其他：失败 | V300R025C00 |
| userInfo | {userState: int, userTimeOut: int} | userState: 用户状态；userTimeOut: 用户超时时间 | V300R025C00 |
| sysTime | str | 本地系统时间；用户状态为在线时携带 | V300R025C00 |
| activeAlarmInfo | {criticalNum: int, majorNum: int, minorNum: int, warningNum: int} | 活动告警数量，分别为紧急、重要、次要、提示级别的告警；用户状态为在线时携带 | V300R025C00 |

userState 取值说明：
- 0：用户在线
- 1：用户被强制退出，提示：该用户在其它地方登录，您已被强制退出
- 2：用户被恢复，提示：用户名和密码已恢复出厂配置，请重新登录
- 其他：用户权限失效，提示：用户权限失效，请重新登录

### 示例
前台请求使用：
```
./get_time_refresh_data.asp?para=
```
平台前台调用：
```
<% GetTimeRefreshdata(para);%>
```
