### 接口名称
set_common_info.asp

### 功能
通用设置接口，根据 Type 参数区分不同的设置操作，具体如下：
- Type=1：提交NETECO参数
- Type=2：提交二次挑战预共享密码
- Type=3：提交时区设置
- Type=4：提交系统时间设置
- Type=5：提交NTP设置
- Type=6：提交IP设置
- Type=7：页面设置到最后一步的完成请求
- Type=8（退化接口）：设置基本配置参数
- Type=9：启动neteco建链测试（此接口仅支持bin4）
- Type=10：启动升级任务
- Type=11：激活已上传的License文件
- Type=12：注销已激活的License文件
- Type=13：启动多升级包到位请求
- Type=14：用户通过web设置日志同步的配置参数
- Type=15：启动南向设备数据导出
- Type=16：停止南向设备导出
- Type=17：设置安全配置信息（WEB_SET_SECURITY_CONFIG_INFO_JS_E）
- Type=18：NTP测试

后台接口：
```
INT32 EMAP_AspSetCommonInfo(INT32 eid, Webs *wp, INT32 argc, CHAR **argv);
```
后台是否记录操作记录：Type=1~7、9~10、14~18 记录操作记录；Type=8（退化接口）不记录操作记录；Type=11、12 由设备管理记录操作记录；Type=13 不记录操作记录；Type=17 否，入侵检测组件自己记录。

### 参数
前台请求使用格式：`set_common_info.asp?Type=type&para1=para1&para2=para2&para3= para3&para4= para4&para5= para5`
平台前台调用：`<% SetCommonInfo (type, para1, para2, para3, para4, para5);%>`

  - selectnum：选中数量
  - val：数组元素值
- para4（json格式）：
```json
{
  "isRecordOperLog": int, // 0:升级成功不记操作日志 1:升级成功记录操作日志，不携带默认是1
  "externPara": int, // bit0标识是否延迟激活，0:不延迟激活 1:延迟激活；bit1标识抢权标记，网管上上传的包，必须有抢权标记才能在web上升级；非必选字段，不传值为0
}
```

### 接口名称
get_recert_enable.asp

### 功能
获取二次认证使能状态，当进行重要操作时，页面会再次弹出输入框，要求再次输入密码，只有密码输入正确后，才会下发进行设置操作。根据 Type 区分不同场景：
