### 接口名称

set_user_info.asp

### 功能

用户信息管理接口（Type 细分功能如下）：
- **type=0**：添加用户
- **type=1**：修改用户信息
- **type=2**：删除用户
- **type=3**：锁定用户
- **type=4**：解锁用户
- **type=5**：增加用户（cjson 格式，V2R3C20 新增）
- **type=6**：修改用户信息（cjson 格式，V2R3C20 新增）
- **type=7**：删除用户信息（cjson 格式，V2R3C20 新增）
- **type=8**：锁定用户（cjson 格式，V2R3C20 新增）
- **type=9**：解锁用户（cjson 格式，V2R2C20 新增）

后台接口：`EMAP_AspSetUserInfo (int eid, Webs *wp, int argc, CHAR **argv)`

后台是否记录操作记录：
- type=0 / 1 / 2 / 4 / 9：记录操作记录；
- type=3 / 5 / 6 / 7 / 8：需记录操作记录；

### 参数

通用请求方式：
```
./set_user_info.asp?type=&para1= &para2= &para3=&para4=&para5=&para6=
```

平台前台调用：`<%SetUserInfo(type, para1, para2, para3,para4,para5,para6);%>`

#### type=0 添加用户

请求信息：
- **Type**：0 —— 请求类型
- **para1 = userName**：用户名
- **para2 = userPassword**：用户密码
- **para3 = userAuthor**：用户权限（0：访客，1 为操作员，2 为工程师，3 为管理员）
- **para4 = userSource**：用户的登录源值（参见：emap_usr_manager.h 中 EMAP_USR_OPERATOR_E 定义）
- **para5 = pwdInfo**：由 `pwdDifferenceTimes~pwdActiveTime~pwdNotifyTime~userOverTime` 组成（红色字段使能密码找回时携带，V2R2C20 增加）：

| 内容 | 分隔符 | 说明 | 变更说明 |
|---|---|---|---|
| pwdDifferenceTimes | ~ | 密码不一致标志（0 为不一致） | |
| pwdActiveTime | ~ | 密码有效期 | |
| pwdNotifyTime | ~ | 密码到期前几天的提醒时间 | |
| userOverTime | ~ | 密码过期时间 | |
| FindPwdMethod | ~ | 密码找回方式 0：不配置（不配置时带后续，填空，占位，便于以后扩展）1：邮箱 2：短信 3：邮箱+短信 | |
| Email | ~ | 邮箱 | |
| Phone | | 手机号 | |
| UsrActiveTime | | 用户有效期 | V2R5C10 新增 |

- **para6 = token**：二次鉴权中 token 信息，set_recert.asp 回复内容

响应信息（信息域）：
- Error："ERR" 或 " "（获取失败）
- Normal：`OK|returnCode`

| 参数 | 分隔符 | 说明 |
|---|---|---|
| OK | | 获取成功 |
| ReturnCode | | 0 表示添加成功，在表格中添加一条用户信息；1 表示添加失败；4 表示用户数量已满，添加失败；8 表示用户名已存在，添加失败；14 表示密码不符合复杂度要求，添加失败；15 表示用户名不合法，添加失败 |

### 接口名称

set_alarm_cfg.asp

### 功能

告警配置接口（Type 细分功能如下）：
- **type=0**：设置告警参数信息（新请求，V2R2C00 新增，app 使用）
- **type=1**：根据设备实例设置告警使能（app 使用）
- **type=2**：根据设备类型设置告警关联继电器（app 使用）
- **type=3**：根据设备类型设置告警关联摄像头（app 使用）
- **type=4**：根据设备类型设置关联音箱
- **type=5**：按实例设置告警关联资源
- **type=6**：按类型设置告警关联继电器
- **type=7**：按实例设置告警关联资源
- **type=8**：根据设备实例设置告警基本参数——告警级别（V2R2C00 新增）
- **type=10**：根据设备实例设置告警关联音响（V2R2C00 新增加，代替 type=1）
- **type=11**：按照类型设置使能
- **type=12**：按设备类型批量设置告警的使能（新请求，V2R2C00 新增）
- **type=13**：按设备类型批量设置告警基本参数（新请求，V2R2C00 新增）
- **type=14**：按实例设置告警关联摄像头

（注：文档中未出现 type=9，直接从 type=8 跳至 type=10。）

后台接口：`extern INT32 EMAP_AspSetAlarmConfigInfo( INT32 eid, Webs *wp, INT32 argc, CHAR **argv);`

后台是否记录操作记录：所有 Type 均“需要记录操作记录；”。
