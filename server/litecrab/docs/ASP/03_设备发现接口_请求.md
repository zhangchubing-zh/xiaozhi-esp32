### 接口名称

get_find_equipinfo.asp

### 功能

该接口用于获取/查询测试设备相关信息，共包含 5 个 Type 变体：

- **Type=0**：获取测试设备操作进度。
- **Type=1**：获取已接入设备列表。
- **Type=2**：查询所有发现设备信息（返回 JSON 数据）。
- **Type=3**：查询端口对应的协议列表（JSON）。
- **Type=4**：根据设备类型 ID，查询该设备类型所有制造商信息（返回 JSON 数据）。

后台接口：`extern INT32 EMAP_AspGetFindEquipInfo(INT32 eid, Webs *wp, INT32 argc, CHAR **argv);`

后台是否记录操作记录：

- Type=0：记录操作记录；
- Type=1：不记录操作记录；
- Type=2：不记录操作记录；
- Type=3：不记录操作记录；
- Type=4：不记录操作记录。
