### 接口名称
set_performance_collect.asp

### 功能
性能数据补采相关功能。
后台接口：EMAP_AspSetPerformanceCollect(int eid, Webs *wp, int argc, CHAR **argv)
后台是否记录操作记录：不需要记录操作记录。

### 参数

**请求信息（请求信息）**，参数名 `para`：

| 名称 | 值 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| type | int | 0：启动性能补采；1：停止性能补采；2：查询性能补采进度。仅 type 为 0 时携带以下字段。 | - |
| equipList | [ {equipId: int}, {equipId: int} ] | 启动补采的设备列表 | - |
| sdrList | [ {collectDays: int}, ... ] | 启动补采的 sdr 类型列表。当前 sdrList 数组大小必须为 5，内容依次为 sdr 数据、小时、日、月、年。collectDays：界面上选择的补采天数，月、年等单位需要转化为天。 | - |

**响应信息（响应信息）**：

| 名称 | 值 | 说明 | 变更版本 |
| --- | --- | --- | --- |
| errCode | int | 0：表示成功；其它值：失败。type 为 2 时携带下面内容。 | - |
| totalState | int | 0：补采结束；1：补采中；2：补采等待；3：补采失败；4：补采停止；5：不支持补采。 | - |
| sdrList | [ { result: int, equipList: [ { equipId: int, state: int, progress: int } ] } ] | sdrList 的 result：含义同上总的状态；state：含义同上总的状态。 | - |

### 示例
前台请求使用：
```
./ set_performance_collect.asp?para=
```
平台前台调用：
```
<% SetPeformanceCollect(para);%>
```

| --- | --- | --- | --- |
